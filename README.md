# ПрофТрек · proftrack-bigchallenges

Настольное приложение (PyQt6) для анализа сообществ ВКонтакте: собирает участников заданных
групп и проверяет, связаны ли «образовательные» сообщества с поступлением их участников в топовые вузы.

Проект сделан в рамках конкурса **«Большие вызовы»**.

---

## Суть

Исследовательская гипотеза простая:

> Участники сообществ образовательных центров чаще поступают в ведущие вузы страны,
> чем участники «обычных» (контрольных) сообществ того же возраста.

Программа проверяет это на данных ВКонтакте и выдаёт числовой результат + график.

### Как считается

1. Берутся два набора ID сообществ: **тестовые** (образовательные центры) и **контрольные** (для сравнения).
2. Через VK API (`groups.getMembers`, поля `bdate, universities`) выгружаются участники обеих выборок.
3. Из даты рождения выделяется **год**, из профиля — **название вуза**.
4. Фильтры отбора:
   - год рождения в диапазоне **2003–2007** (`2002 < year < 2008`) — то есть выпускники школ, уже поступившие в вуз;
   - вуз в профиле **указан**;
   - участники контрольной группы, которые уже есть в тестовой, **исключаются** (чтобы выборки не пересекались).
5. Вуз сравнивается со встроенным списком ~30 ведущих университетов (МГУ, МФТИ, ВШЭ, ИТМО, СПбГУ и др.).
   Совпал — `universities = 1`, не совпал — `universities = 0`.
6. Считается **коэффициент корреляции Спирмена** между признаком `data_from` (откуда участник: 1 — образовательное
   сообщество, 0 — контрольное) и `universities` (топовый вуз или нет).
7. Результат сохраняется в `test.csv`, строится столбчатая диаграмма долей, а в интерфейсе выводится
   текстовая интерпретация силы связи:

   | \|r\| | Интерпретация в программе |
   |---|---|
   | 0 < r ≤ 0.4 | слабая положительная зависимость |
   | r > 0.4 | подтверждающая положительная зависимость |
   | −0.4 ≤ r < 0 | слабая отрицательная зависимость |
   | r < −0.4 | подтверждающая отрицательная зависимость |

### Пример результата (на данных, лежащих в репозитории)

```
Спирмен: 0.0952  → «слабая подтверждающая, но положительная зависимость»
Тестовые сообщества  (data_from=1): 13.3 % учатся в топ-вузе
Контрольные сообщества (data_from=0):  7.5 %
Всего записей после фильтрации: 1196 (годы рождения 2003–2007)
```

## Структура проекта

```
proftrack-bigchallenges/
├── main.py                 # всё приложение: загрузка данных + анализ + GUI
├── requirements.txt        # зависимости (неполные, см. раздел «Установка»)
├── .env.example            # шаблон для токена VK API
├── ui/
│   ├── main.ui             # основной дизайн окна (используется программой)
│   ├── downloader_window.ui# ранние варианты дизайна, в коде не используются
│   └── main_window.ui      #
├── all_test.csv            # сырые данные тестовых сообществ (пример, ~14 тыс. строк)
├── all_contr.csv           # сырые данные контрольных сообществ (пример, ~151 тыс. строк)
└── test.csv                # результат фильтрации и анализа (~1,2 тыс. строк)
```

### Что внутри `main.py`

| Объект | Назначение |
|---|---|
| `LoaderThread(QThread)` | Фоновая выгрузка участников из VK, пишет `all_contr.csv` и `all_test.csv` |
| `MyWidget(QMainWindow)` | Главное окно: кнопки «Начать Загрузку» и «Начать анализ», поля ввода ID, метки статуса |
| `MyWidget.run()` | Основная аналитика: фильтрация, разметка вузов, корреляция, график |
| `resource_path()` | Поддержка запуска из собранного PyInstaller-бандла (`sys._MEIPASS`) |
| `BASE_DIR` | Каталог, куда кладутся CSV: рядом со скриптом или рядом с `.exe` |

### Форматы данных

`all_test.csv` / `all_contr.csv` — сырой ответ VK API:

```
id, first_name, last_name, can_access_closed, is_closed, bdate, universities, deactivated
```

`test.csv` — очищенная выборка, на которой считается корреляция:

```
id, year, universities, data_from
179904699, 2004, 1, 1     # 179904699 — ID пользователя, 2004 — год рождения,
                          # 1 — топ-вуз, 1 — пришёл из образовательного сообщества
```

## Установка

### 1. Требования

- **Python 3.12+** (в коде используются f-строки с вложенными одинаковыми кавычками;
  в `.idea` проект настроен на Python 3.14).

### 2. Зависимости

`requirements.txt` содержит только часть пакетов (`numpy`, `pandas`, `urllib3`).
Для запуска дополнительно нужны `PyQt6`, `python-dotenv`, `matplotlib`, `vk_api`:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
pip install PyQt6 python-dotenv matplotlib vk_api
```

### 3. Токен VK API

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

Откройте `.env` и впишите свой токен (личный токен пользователя или сервисный ключ с доступом к `groups`):

```
TOKEN = 'vk1.a.xxxxxxxxxxxxxxxxxxxxx'
```

> Токен создаётся в настройках VK: **VK ID → Безопасность → Работа с API**.
> `.env` в репозиторий не коммитим.

### 4. Запуск

Запускать **из корня проекта** — дизайн `./ui/main.ui` ищется относительно текущей директории:

```bash
cd proftrack-bigchallenges
python main.py
```

## Как пользоваться

1. В поле **«Введите ID сообществ образовательных центров»** укажите ID тестовых групп
   через запятую и пробел, например: `141995075, 127973328`.
2. В поле **«Введите ID сообществ для сравнения»** — ID контрольных групп, например: `46936573, 987654321`.
3. Нажмите **«Начать Загрузку»**. Кнопка блокируется на время работы, прогресс пишется в нижнюю метку
   (`Загружено данных тестовых N`). По окончании появятся `all_test.csv` и `all_contr.csv` рядом с программой.
4. Нажмите **«Начать анализ»** — откроется окно matplotlib «Результаты анализа групп»
   со столбчатой диаграммой долей, а в метке приложения появится значение корреляции и её интерпретация.
   Очищенная выборка сохранится в `test.csv`.

> **Можно не скачивать данные заново:** в репозитории уже лежат примеры `all_test.csv` и `all_contr.csv`.
> После клонирования достаточно нажать «Начать анализ» — расчёт пройдёт на них.

**Где взять ID сообщества:** откройте группу ВКонтакте — ID виден в адресе (`vk.com/club141995075` → `141995075`)
или на странице «Управление → Работа с API».

## Сборка в исполняемый файл

Код уже подготовлен под PyInstaller (`resource_path`, проверка `sys.frozen`):

```bash
pip install pyinstaller

# Windows
pyinstaller --noconfirm --onefile --windowed --name ProfTrack --add-data "ui;ui" main.py

# Linux / macOS (разделитель — двоеточие)
pyinstaller --noconfirm --onefile --windowed --name ProfTrack --add-data "ui:ui" main.py
```

Исполняемый файл появится в `dist/`. CSV-файлы программа пишет **рядом с `.exe`**,
а `.env` должен лежать в рабочей директории, из которой запускается приложение.

## Подводные камни и известные ограничения

- **Неполный `requirements.txt`** — `PyQt6`, `python-dotenv`, `matplotlib`, `vk_api` в нём не указаны (см. «Установка»).
- **Только ошибка №9 обрабатывается.** При `ApiError` с кодом 9 (flood control) поток ждёт 60 секунд и повторяет
  запрос. При любом другом коде ошибки исключение «проглатывается», смещение не меняется → возможен бесконечный цикл.
  Если загрузка «зависла», смотрите консоль и правьте ветку `except`.
- **Список «топовых» вузов зашит в коде** (`list_of_best` в `MyWidget.run()`). Сравнение идёт по подстроке
  (`str.contains`), поэтому короткие аббревиатуры вроде `ФУ` или `НМИЦ` могут давать ложные срабатывания
  (например, `ФУ` найдётся внутри многих названий). При доработке лучше вынести список в конфиг и уточнить matching.
- **Дубликаты не удаляются.** Если один человек состоит в двух тестовых сообществах, он попадёт в выборку дважды —
  `drop_duplicates(subset='id')` не вызывается.
- **Лимит выгрузки — 150 000 участников** на одно сообщество (`offset >= 150000`), страницы по 1000, пауза 0.5 с.
- **Нужен непустой `bdate` с годом.** Профили с датой вида `31.7` (без года) и закрытые/удалённые страницы
  отсеиваются автоматически (`pd.to_numeric(errors='coerce')`), из-за чего итоговая выборка сильно меньше сырой
  (в примере: 165 тыс. → 1196 записей). Это нормальное поведение, а не ошибка.
- **`TOKEN` читается при старте модуля.** Без валидного токена окно откроется, но загрузка упадёт на первом запросе.
- **Запуск из другой директории сломает UI** — путь к `.ui`-файлу относительный.
- **В репозиторий закоммичены `.idea/` и большие CSV** (≈8 МБ). Для чистоты стоит добавить `.gitignore`
  (`.venv/`, `.env`, `__pycache__/`, `.idea/`, `build/`, `dist/`) и, при желании, убрать CSV из истории.
- **Корреляция Спирмена на бинарных признаках** — по сути мера ассоциации; для строгого вывода о значимости
  стоит добавить p-value (`scipy.stats.spearmanr`) и размер выборок.
